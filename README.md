# PC Component Comparator

Приложение для сравнения комплектующих ПК с актуальными ценами из популярных российских интернет-магазинов.

## Основные возможности

- Меню категорий комплектующих (процессоры, видеокарты, МП, ОЗУ, SSD и т.д.)
- Поиск по всем компонентам или внутри выбранной категории
- Чекбокс «В сравнение» на карточке (появляется при наведении)
- Выбор от 2 до 4 позиций одной категории → кнопка «Перейти к сравнению»
- Сравнение только внутри одного типа комплектующих
- Обновление базы по кнопке (начальное наполнение товарами отсутствует)

## Стек

- **Backend**: Python 3.11+ / FastAPI + SQLAlchemy + SQLite
- **Frontend**: React 18 + Vite + TypeScript + React Router
- **Данные**: категории/магазины создаются по кнопке «Обновить базу»; товары — после подключения API (например ReefAPI для DNS)

## Запуск

### Backend

```bash
cd pc-component-comparator
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173  
API проксируется на http://localhost:8000

### Первый запуск

1. Запустите backend и frontend.
2. Нажмите «Обновить базу» — создадутся категории и магазины.
3. Для реальных товаров нужен API-ключ (см. `.env.example`).

## API (основное)

| Метод | Путь | Описание |
|--------|------|----------|
| GET | `/categories` | Список категорий |
| GET | `/components?category=&q=` | Список с поиском и фильтром |
| GET | `/components/{id}` | Детали компонента |
| GET | `/compare?ids=1,2,3` | Сравнение (2–4, одна категория) |
| POST | `/update-database` | Подготовка категорий/магазинов |
