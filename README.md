# PC Component Comparator

Приложение для сравнения комплектующих ПК с актуальными ценами из популярных российских интернет-магазинов.

## Основные возможности

- Сравнение комплектующих по характеристикам и ценам
- Обновление базы данных по кнопке (начальное наполнение отсутствует)
- Источники данных:
  - Характеристики: открытые базы (BuildCores OpenDB, TechPowerUp и аналоги), сайты производителей
  - Цены и наличие: DNS (через сторонние API, например ReefAPI), далее — Ситилинк, Регард

## Стек технологий

- **Backend**: Python 3.11+ / FastAPI
- **База данных**: SQLite (начально) + SQLAlchemy, возможен переход на PostgreSQL
- **Frontend**: React + Vite (или простой HTML/шаблоны на первом этапе)
- **Обновление данных**: эндпоинт с кнопкой «Обновить базу», который запускает загрузку данных

## Статус

Репозиторий создан. Начальное наполнение базы отсутствует — данные появляются только после нажатия кнопки обновления.

## План разработки

1. Схема БД и модели данных
2. Backend API (круд компонентов, сравнение, обновление)
3. Логика загрузки данных (кнопка обновления)
4. Frontend интерфейс сравнения
5. Интеграция с источниками цен (начать с DNS)
